# LJT-Homepage

Personal homepage of Junteng Liu, built by forking the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template for GitHub Pages.

## Site pages

- **About** (`/`): biography, research interests, academic background, research experience, skills, publications, and contact information.
- **Publications** (`/publications/`): publication list.

## Content

Site content lives in:

- `_config.yml`: site settings and author sidebar.
- `_data/navigation.yml`: navigation menu.
- `_pages/about.md`: the about page.
- `_pages/publications.html` and `_publications/`: the publications subpage and publication entries.
